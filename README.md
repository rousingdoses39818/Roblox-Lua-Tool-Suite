### Do I need to disable my anticomponent?

Some anticomponent software may flag executor files due to their nature of injecting code. You may need to add exceptions, but we recommend evaluating your security settings carefully.

### Are these tools free?

The XCutors repository itself is free. Some individual executors included may have their own licensing or key systems, which are managed separately by their respective developers.

### How do I update the executors?

Check the GitHub repository for new releases. Download the updated package and replace the files in your existing installation folder.

### Does this work on Mac or Linux?

No, the XCutors collection and all included executors are designed specifically for the Windows operating system.

### What if an executor stops working?

### Can I add my own scripts to the loader?

Yes, the universal loader is designed to manage and execute any compatible Lua script you provide. Simply place your scripts in the designated folder or use the load function in-game.
